# Din Din

Минимальный каркас одностраничного лендинга для мобильного приложения Din Din (доставка еды).

## Стек

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
- ESLint
- Prettier

## Запуск

```bash
npm install
npm run dev
```

## Структура

```
src/
├── app/           # маршруты (/, /privacy)
├── components/
│   ├── layout/    # общие layout-компоненты
│   ├── sections/  # секции лендинга
│   └── ui/        # переиспользуемые UI-элементы
├── assets/        # изображения и иконки
├── constants/
├── types/
└── utils/
```
